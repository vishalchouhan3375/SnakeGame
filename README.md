🐍 Snake Game in Java
A classic Snake Game built using Java. The player controls a snake to eat food, grow longer, and avoid hitting the walls or itself. This project is a fun way to practice object-oriented programming and GUI design with Java Swing.

🎮 Features
Smooth keyboard controls

Real-time movement and collision detection

Score tracking

Game over and restart functionality

Simple and clean GUI using Swing

🛠️ Tech Stack
Java (JDK 8 or higher)

Java Swing (for GUI)
